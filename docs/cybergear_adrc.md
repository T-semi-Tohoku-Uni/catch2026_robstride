# CyberGearの外部位置制御（LADRC）

通常の位置決めを、内蔵の運動制御モードから電流モード＋3次の線形ESOに切り替える。
原点復帰の速度制御は従来どおり。変更箇所は`cybergear.c/.h`と、
`main.c`の原点復帰完了時・通常制御の呼び出しだけ。

## モデルと制御則

出力軸の角度を`theta`、Iq指令を`current`として、
`theta_ddot = b0 * current + disturbance`と置く。
`b0`は概算の出力軸トルク定数／出力軸換算イナーシャ（rad/s²/A）。
ESOは位置のみから位置・速度・加速度相当の総外乱を推定する。
受信速度・受信トルクは制御には使用しない。

```text
current_request = (wc² * (reference - estimated_position)
                   - 2 * wc * estimated_velocity - estimated_disturbance) / b0
```

重力・摩擦・他軸との干渉に加え、実際の入力ゲインと`b0`の差も総外乱に含める。
イナーシャ自体を同定する方式ではない。補償に必要な電流が上限内で、
外乱変化をESOが追従できれば、一定外乱による定常偏差の低減を期待できる。
大きすぎるモデル誤差、急激な変動、機械共振、バックラッシュまで安定性を保証するものではない。

ESOは前回の電流制限・変化率制限後の送信指令で予測し、位置受信値で補正する。
実測の更新間隔`dt`から離散極`exp(-wo * dt)`を計算する。
同一受信時刻の位置を繰り返し補正に使わず、その間は前回電流を再送して応答を要求する。
既存の主ループ（十数ms）を使用するため、CAN応答から制御演算までの遅れは残る。

## 調整値

すべて`Core/Src/cybergear.c`冒頭の`CYBERGEAR_ADRC_*`で設定する。
以下は実機同定前の試運転用初期値であり、この機構での安定性は未確認。

| 定数の末尾 | 初期値 | 意味 |
| --- | ---: | --- |
| `B0_RAD_S2_PER_A` | 10 | 公称入力ゲイン。実機の概算値への置換が必要 |
| `CONTROL_RAD_S` | 3 | 位置制御帯域wc（rad/s、Hzではない） |
| `OBSERVER_RAD_S` | 12 | ESO帯域wo（rad/s） |
| `CURRENT_LIMIT_A` | 1 | Iq指令の絶対値上限（A） |
| `CURRENT_SLEW_A_S` | 5 | Iq指令の変化率上限（A/s） |
| `REFERENCE_RAD_S` | 0.5 | 内部目標位置の変化率上限（rad/s）。実速度の制限ではない |
| `FEEDBACK_TIMEOUT_MS` | 100 | 有効な初回応答の待ち時間／受信値の有効期限（ms） |
| `MAX_STEP_MS` | 50 | 初期化後、新しい位置で制御を更新できない時間の上限（ms） |

まず、正の電流で正方向に加速することと`b0`の概算を確認する。
機構が許容する低電流・小変位で応答を見て、必要に応じてwcを調整する。
woを高くすると位置量子化や遅延への感度が上がるため、帯域だけを上げて発振を抑えようとしない。
電流上限は機構・負荷に合わせ、プロトコルのIq範囲±23 Aを超えないこと。
電流モードの出力制限は送信Iq自身に適用している。

## 起動・停止

`cybergear_start_position_adrc()`は停止→電流モード→Iq=0→有効化の順に送信する。
起動時は新たな運転中フィードバックを待ち、その位置から目標を立ち上げる。
`cybergear_control_position_adrc()`は毎ループ呼び出す。
NaN/Inf・範囲外の目標、モーター異常、応答途絶、長すぎる更新間隔、送信失敗を検出すると
停止を要求して`false`を返す。以降の呼び出しでも停止送信を再試行し、自動復帰はしない。
再開には原因を解消して`cybergear_start_position_adrc()`を明示的に呼ぶ。
停止・原点変更・モード変更・異常クリアでもADRCを無効化する。

送信成功はHALのFIFO受付を意味し、モーター側での適用確認ではない。
CANが完全に断線した場合やMCU自体が止まった場合、このソフトウェアからの停止指令は保証できない。
動作中に別のAPIで同じモーターへ電流・運動指令を書き込まないこと。

## 確認内容・参考

Arm GNUツールチェーンでDebugビルドを確認。
実際の`cybergear.c`をHALスタブと接続したホスト検証では、一定外乱、位置量子化、
13～16 msの周期変動、1周期相当の位置遅延、入力ゲイン5↔20の変化で収束を確認した。
電流上限・変化率、受信停止、モーター異常、不正目標、送信失敗、停止保持、時刻周回も確認。
これは簡略化したモデル上の確認であり、実機の調整・安定性確認は別途必要。
